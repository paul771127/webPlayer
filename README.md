# webPlayer

手勢控制的 YouTube 播放器：https://paul771127.github.io/webPlayer/

## 操作
- 右滑 / 左滑：快進 / 倒退（秒數可在控制列調整）
- 上滑 / 下滑：音量增減（iPhone 不支援）
- 單擊：播放 / 暫停；雙擊：進入 / 離開全螢幕；全螢幕時長按也可退出
- 控制列：進度條（可拖曳）、跳轉秒數、播放速度、全螢幕；全螢幕時底部有細進度線

## 瀏覽
- 搜尋：關鍵字 + 上傳時間、影片長度、排序篩選
- 頻道：點正在播放影片的頻道名稱，瀏覽該頻道所有影片
- 訂閱：存在這台裝置，下次從「訂閱」直接進頻道
- 上方輸入框也可貼影片網址（直接播放）或頻道網址（開頻道）

搜尋與頻道需要 YouTube Data API v3 金鑰，在「設定」頁貼上，只存在本機瀏覽器。

## 檔案
- `index.html` 版面
- `style.css` 樣式
- `app.js` 播放器、手勢、控制列、全螢幕、續播
- `browse.js` 搜尋、頻道、訂閱、設定
