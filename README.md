# webPlayer

手勢控制的 YouTube 播放器：https://paul771127.github.io/webPlayer/

## 操作
- 右滑 / 左滑：快進 / 倒退（秒數可在控制列調整）
- 上滑 / 下滑：音量增減（iPhone 不支援）
- 單擊：播放 / 暫停；雙擊：進入 / 離開全螢幕；全螢幕時長按也可退出
- 控制列：進度條（可拖曳）、跳轉秒數、播放速度、播放模式（依序／隨機 × 不循環／全部循環／單曲循環）、全螢幕；全螢幕時底部有細進度線

## 瀏覽
- 搜尋：關鍵字 + 上傳時間、影片長度、排序篩選
- 頻道：點正在播放影片的頻道名稱，瀏覽該頻道所有影片
- 訂閱：存在這台裝置，下次從「訂閱」直接進頻道
- 劇集：集中找短劇／動畫／劇集的整季系列（播放清單）或合輯長片，自動排除預告、花絮、解說；
  系列頁列出全部集數、可反轉順序、播完自動下一集，「繼續觀看」記住看到第幾集
- 本機：播放手機裡的影片檔（可選多個或整個資料夾），依檔名／格式／長度篩選，依名稱（第2集排在第10集前）、日期、大小、長度排序；有縮圖、觀看進度條，播完自動下一個
- 播放清單／專輯：貼含 list= 的網址，或在搜尋選「播放清單／專輯」；可勾選要播哪些，依播放模式連續播
- 上方輸入框也可貼影片網址（直接播放）或頻道網址（開頻道）

播放清單／專輯（含 YouTube 合輯 Mix）不用金鑰也能播；搜尋、劇集搜尋與頻道需要 YouTube Data API v3 金鑰，在「設定」頁貼上，只存在本機瀏覽器。

## 檔案
- `index.html` 版面
- `style.css` 樣式
- `app.js` 播放器、手勢、控制列、全螢幕、續播
- `browse.js` 搜尋、頻道、訂閱、設定
- `series.js` 劇集搜尋、系列頁、自動下一集、追劇進度
- `local.js` 本機影片清單、篩選排序、縮圖、連續播放
- `config.js` 內建 API 金鑰（選填）
